# 🏋️ Gym Management System by Square Goals

A complete Python-based management system for gyms and fitness centers.  
It provides an easy-to-use terminal interface for Admins, Trainers, and Members to handle all daily operations.



## 🚀 Features

### 👩‍💼 Admin Panel
- Add or remove members and trainers  
- Create class schedules and assign tasks  
- View attendance and payment charts  
- Manage maintenance and equipment  
- Generate reports and track performance  
- Add membership packages and assign them to members

### 🧑‍🏫 Trainer Panel
- Add training programs  
- View assigned tasks and schedules  
- Update member progress  
- Manage personal training sessions  
- Request equipment maintenance  

### 💪 Member Panel
- Make payments  
- Book trainers or classes  
- View schedules and progress  
- Mark attendance and give feedback  
- Edit profile and see announcements  

### 🤖 AI Chatbot
A simple keyword-based chatbot that answers basic gym-related questions such as:
- Gym timings  
- Trainer bookings  
- Class schedules  
- Payment and attendance instructions  

---

## 🧩 Tech Stack

- **Language:** Python 3  
- **Libraries Used:**  
  - `matplotlib` for charts  
  - `pandas` for data handling  
  - `getpass`, `os`, and `datetime` for file and user management
